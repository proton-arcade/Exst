Plain text powered arcade

Drop in a game, paste one block, and the shelf updates itself.

Games and folders are loaded from files in data/. No database, no build step, no template maze — just IDs, paths, icons, and folder lists you can edit.

Adding a game is this simple: 
[game]
id=my-game
title=My Game
path=games/my-game.html
icon=assets/images/my-game.svg
