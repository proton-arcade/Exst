Made for a quick escape

Exst Arcade is a free, lightweight home for browser games — no accounts, subscriptions, or downloads required. The library is yours to fill: drop a game into website/games/, paste one [game] block into website/data/games.js, and refresh. The same file documents every field, including hero=true for the spotlight carousel.

Look inspired by JuegoAmigo.github.io and the zuix-web-flix template. Game artwork is AI-generated.
