# Games live here

Drop each game into this folder, then describe it in `../data/games.js` with one
`[game]` block.

- **Single file** — `website/games/retro-pong.html` → `path=games/retro-pong.html`
- **Whole folder** — unzip a download to `website/games/retro-pong/index.html`
  → `path=games/retro-pong/index.html`

The folder is intentionally empty: the arcade starts with no library, and every
game in `../data/games.js` is one you chose to add.

Only add games you have the right to run or share.
